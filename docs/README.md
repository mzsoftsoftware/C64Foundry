## Keeping these documents current

Architecture documents describe stable responsibilities and agreed design decisions. Work-package documents describe the current implementation task and are updated as decisions are made and code is completed.

When an architectural decision changes, update the relevant architecture document and the current work-package document. Do not leave contradictory historical proposals in the active documentation.
